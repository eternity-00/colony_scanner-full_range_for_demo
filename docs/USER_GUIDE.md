## 1. 프로그램 소개

이 프로그램은 Colony Scanner LCD의 React UI와 가상 스캐너 4대를 함께 실행하는 데모다. 실제 장비가 없어도 다음 흐름을 시험할 수 있다.

- 트레이 슬롯에 플레이트 등록
- 촬영 명령과 6단계 진행 확인
- 일시정지·재개·비상 정지
- 합성 촬영 영상과 최근 영상 5장 보존
- PC 링크 단절과 미전송 재전송
- 장비 연결 끊김, 도어, 카메라, Z축, 히터 오류
- 명령 TX, ACK/NACK, 장비 이벤트 확인
- 반출 후 영상 삭제와 이력 유지

화면에 표시되는 온도·CO₂·모터·조명·영상은 모두 가상 값이다. 실제 인큐베이터나 스캐너에는 명령을 보내지 않는다.

## 2. 실행 방법

### 2.1 데스크톱에서 실행

1. 바탕화면에서 **Colony Scanner React Demo** 아이콘을 더블클릭한다.
2. 브라우저 앱 창이 열릴 때까지 기다린다.
3. 헤더에 **VIRTUAL**, **서버 실시간 연결**, **장비 4/4**가 표시되는지 확인한다.

서버가 이미 실행 중이면 기존 서버를 사용한다. 서버가 없으면 자동으로 빌드하고 시작하므로 최초 실행은 조금 더 걸릴 수 있다.

### 2.2 터미널에서 실행

```sh
cd /home/miru/cc-lcd/react-demo
./run-demo.sh
```

브라우저에서 다음 주소를 연다.

```text
http://127.0.0.1:8787
```

터미널에서 실행한 경우 `Ctrl+C`로 종료한다. 바탕화면 실행처럼 백그라운드로 시작한 서버는 다음 명령으로 종료한다.

```sh
cd /home/miru/cc-lcd/react-demo
./stop-demo.sh
```

## 3. 화면 구성

### 3.1 헤더

| 표시 | 의미 |

| VIRTUAL | 실장비가 아닌 가상장비 모드 |

| 서버 재연결 중 | 서버 연결 끊김 또는 재시도 중 |
| 온도 / CO₂ | 가상장비 4대의 평균값 |
| 장비 N/4 | 연결 상태가 true인 가상장비 수 |

### 3.2 하단 메뉴

| 메뉴 | 용도 |
|---|---|
| 현황 | 전체 장비와 트레이 상태 확인 |
| 등록 | 플레이트 수납 위치와 투입 시각 등록 |
| 진행 | 현재 및 최근 장비 작업 확인·제어 |
| 이력 | 플레이트와 촬영 이력 검색 |

| 설정 | 검사 루틴, 자동 촬영, 환경 목표값 |

## 4. 데모 시작 전 확인

1. 헤더가 **서버 실시간 연결**인지 확인한다.
2. **가상장비** 탭을 연다.
3. 사용할 스캐너의 **장비 연결**과 **PC 전송 링크**가 켜져 있는지 확인한다.
4. **도어 센서**와 **카메라 실패**가 꺼져 있는지 확인한다.
5. 장비 상태가 **대기**인지 확인한다.

오류가 표시되면 도어를 닫은 뒤 **오류 해제**를 누른다. 연결이 끊긴 장비는 먼저 **장비 연결**을 켠다.

## 5. 플레이트 등록

1. 하단의 **등록**을 누른다.
2. `SCANNER 1`~`SCANNER 4` 중 사용할 장비를 선택한다.
3. 트레이의 흰색 빈 슬롯을 누른다.
4. 투입 시각을 확인하거나 수정한다.
5. 공통 검사 루틴과 첫 촬영 예정 시각을 확인한다.
6. **등록하고 수납**을 누른다.
7. 상세 화면에서 서버가 만든 `PL-XXXXXXXX` ID와 위치를 확인한다.

다음 상태에서는 장비 선택 또는 등록 버튼이 비활성화된다.

- 장비 연결 끊김
- 도어 열림
- 장비 오류
- 장비 작업 중
- 24슬롯 만재
- 선택 슬롯에 이미 플레이트 수납

UI 등록은 메타데이터 기록이다. 실제 플레이트를 물리 트레이에 넣는 동작은 운영자가 수행해야 한다.

## 6. 수동 촬영

1. **현황**에서 대상 스캐너의 **상세**를 누른다.
2. 왼쪽 트레이에서 대상 슬롯을 선택한다.
3. 플레이트 ID와 미전송 건수를 확인한다.
4. **지금 촬영**을 누른다.
5. **진행** 화면에서 6단계를 확인한다.

촬영 단계:

1. 이송
2. 물기 제거
3. 촬영
4. 수납 복귀
5. 전송
6. PC 저장

기본 가상 단계는 각각 약 1.6초다. 완료하면 플레이트 촬영 이력에 새 회차가 생기고 가상 6-well 영상이 저장된다.

## 7. 촬영 일시정지와 재개

촬영 작업 자체를 정지하려면 **진행** 화면을 사용한다.

1. 진행 중인 작업 카드에서 **일시정지**를 누른다.
2. 진행률과 축 출력이 멈추고 상태가 `paused`로 바뀌는지 확인한다.
3. **재개**를 누른다.

도어가 열렸거나 오류가 있으면 재개할 수 없다. 가상장비 화면에서 도어를 닫고 오류를 해제한 다음 다시 시도한다.

상세 화면의 **일정 일시정지**는 현재 작업을 멈추는 버튼이 아니다. 해당 플레이트를 자동 촬영 스케줄러 대상에서 제외한다. 다시 포함하려면 **일정 재개**를 누른다.

## 8. 비상 정지

1. 진행 화면에서 **비상 정지**를 누른다.
2. 확인 창에서 위험 동작 설명을 읽는다.
3. 확인하면 현재 작업이 실패로 종료되고 장비에 `ESTOP` 오류가 설정된다.
4. **장비** 또는 **가상장비** 화면에서 **오류 해제**를 눌러 복구한다.

이 버튼은 가상 상태만 정지한다. 실제 장비의 물리 비상정지 기능이 아니다.

## 9. 영상 확인과 보존

1. 상세 화면의 **촬영 이력** 표를 확인한다.
2. 영상이 보유된 회차의 **보기**를 누른다.
3. 합성 6-well 이미지를 확인한다.

보존 규칙:

- 성공 영상은 플레이트당 최근 5장만 보유한다.
- 여섯 번째 성공 촬영부터 가장 오래된 성공 영상이 만료된다.
- 실패 회차는 영상이 없으며 5장 계산에서 제외한다.
- 만료된 회차의 촬영 시각과 상태는 계속 남는다.
- 반출하면 보유 영상은 모두 만료되고 이력은 유지된다.

합성 SVG는 UI 기능 시험용이다. 실제 콜로니 판독이나 카메라 화질 평가에 사용하지 않는다.

## 10. PC 링크 단절과 재전송 시험

1. **가상장비**에서 대상 스캐너의 **PC 전송 링크**를 끈다.
2. 해당 스캐너의 플레이트를 촬영한다.
3. 상세 화면에서 새 회차가 **미전송**인지 확인한다.
4. 같은 과정을 반복하면 미전송 건수가 증가한다.
5. 미전송 2건 이상이면 현황 경고와 WARN 로그를 확인한다.
6. 가상장비 화면에서 **PC 전송 링크**를 다시 켠다.
7. 상세 화면에서 **재전송**을 누른다.

재전송은 현재 서버에 보유 중인 영상만 처리한다. 보존 기간 만료 또는 반출로 삭제된 영상은 재전송할 수 없다.

## 11. 장비 입력과 오류 시험

### 11.1 장비 연결

- 끄기: 가상장비가 오프라인이 되며 진행 작업은 실패한다.
- 켜기: 통신 입력은 복구되지만 기존 fault는 자동 해제되지 않을 수 있다.

### 11.2 도어 센서

- 켜기: 도어 열림을 의미한다. 진행 작업은 실패하고 `DOOR_OPEN` 오류가 설정된다.
- 끄기: 도어 닫힘을 의미한다. 이후 **오류 해제**가 필요하다.

### 11.3 카메라 실패

- 켜기: 다음 촬영의 3단계에서 `CAMERA_TIMEOUT` 실패가 발생한다.
- 시험 후 끄고 오류를 해제한다.

### 11.4 오류 주입

| 버튼 | 오류 코드 | 의미 |
|---|---|---|
| Z축 오류 주입 | Z_LIMIT | 가상 Z축 리밋 오류 |
| 히터 오류 주입 | HEATER | 가상 히터 오류 |

오류가 있으면 새 촬영·원점·캘리브레이션·초기화 명령이 거부된다. 도어가 닫힌 상태에서 오류 해제를 실행한다.

## 12. 장비 출력 확인

**진행** 화면에서 다음 값을 확인한다.

| 출력 | 확인 내용 |
|---|---|
| 진행률 | 0~100% 증가 |
| 현재 단계 | 활성 단계가 파란색, 완료 단계가 녹색 |
| Z축 위치 | 이송·촬영 과정에서 변화, 완료 시 0mm |
| 조명 출력 | 촬영 단계에서 ON |
| 히터 접촉 | 물기 제거 단계에서 ON |

화면 갱신은 서버의 SSE 상태 이벤트를 사용한다. 새로고침 없이 값이 바뀌어야 정상이다.

## 13. 원점·캘리브레이션·초기화

**장비** 화면의 각 스캐너 카드에서 실행한다.

- **원점 복귀**: 3단계 가상 구동 작업
- **캘리브레이션**: 3단계 가상 보정 작업
- **모듈 초기화**: 3단계 가상 초기화 작업
- **오류 해제**: fault를 제거

장비가 연결되고, 도어가 닫혔으며, 오류와 진행 작업이 없어야 구동 명령이 수락된다. 완료 여부는 진행 화면과 이벤트 로그에서 확인한다.

## 14. I/O 패킷 모니터 읽기

**가상장비** 화면 오른쪽에는 최근 50개 I/O 기록이 표시된다. 서버 상태에는 최근 150개가 보관된다.

| 방향/종류 | 의미 |
|---|---|
| TX | UI 또는 스케줄러가 Controller에 보낸 명령 |
| RX ACK | 명령 수락 |
| RX NACK | 검증·인터록에 의한 명령 거부 |
| RX job.started | 장비 작업 시작 |
| RX job.stage | 작업 단계 변경 |
| RX job.paused | 작업 일시정지 |
| RX job.running | 작업 재개 |
| RX job.completed | 작업 성공 완료 |
| RX job.failed | 작업 실패 |
| RX simulator.input | 가상 입력 적용 |

I/O 레코드에는 장비 번호, 시각, requestId와 JSON payload가 기록된다. 버튼을 눌렀는데 화면이 변하지 않으면 가장 최근 NACK의 코드와 메시지를 확인한다.

## 15. 자동 촬영 설정

1. **설정** 탭을 연다.
2. 촬영 주기, 배양 기간, 첫 촬영 지연을 입력한다.
3. **저장**을 누른다.
4. **자동 촬영 스케줄러**를 켠다.

입력 범위:

| 항목 | 범위 |
|---|---|
| 촬영 주기 | 1~48시간, 정수 |
| 배양 기간 | 1~90일, 정수 |
| 첫 촬영 지연 | 0~720분, 15분 단위 |

자동 촬영은 연결·도어·오류·작업 상태를 확인하고 예정 시각이 지난 플레이트를 장비당 하나씩 처리한다. 데모 기본 플레이트는 과거 시각으로 구성되어 있으므로 자동 촬영을 켜면 즉시 작업이 연속 실행될 수 있다.

시험이 끝나면 자동 스케줄러를 끄는 것을 권장한다.

## 16. 가상 온도와 CO₂

1. **설정**에서 목표 온도와 CO₂를 입력한다.
2. **목표값 적용**을 누른다.
3. 헤더 또는 장비 화면에서 현재값이 목표값에 천천히 수렴하는지 확인한다.

온도 범위는 4~55℃, CO₂ 범위는 0~20%다. 이 값은 단순한 UI 시험 모델이며 실제 열역학·가스 제어 시뮬레이션이 아니다.

## 17. 플레이트 반출

1. 상세 화면에서 대상 플레이트를 선택한다.
2. **반출**을 누른다.
3. 확인 창에서 영상 삭제 안내를 확인한다.
4. 확인하면 슬롯이 비고 보유 영상 파일이 삭제된다.
5. **이력**에서 **반출 이력 포함**을 켜고 플레이트 ID를 검색한다.
6. 촬영 회차와 메타데이터가 남아 있는지 확인한다.

진행 중인 작업의 플레이트는 반출할 수 없다. 작업을 완료하거나 비상 정지한 뒤 실행한다.

## 19. 문제 해결

## 20. 시험 권장 시나리오

### 시나리오 A — 정상 촬영

1. SCANNER 3의 모든 입력을 정상으로 설정한다.
2. 빈 슬롯에 플레이트를 등록한다.
3. 지금 촬영을 실행한다.
4. 6단계와 출력 변화를 확인한다.
5. 촬영 이력과 합성 영상을 확인한다.

### 시나리오 B — PC 전송 장애

1. PC 전송 링크를 끈다.
2. 같은 플레이트를 2회 촬영한다.
3. 미전송 경고와 로그를 확인한다.
4. 링크를 켜고 재전송한다.

### 시나리오 C — 도어 인터록

1. 촬영을 시작한다.
2. 진행 중 도어 센서를 켠다.
3. 작업 실패, 출력 OFF, DOOR_OPEN 오류를 확인한다.
4. 도어를 닫고 오류를 해제한다.

### 시나리오 D — 카메라 실패

1. 카메라 실패 입력을 켠다.
2. 촬영을 시작한다.
3. 촬영 단계에서 CAMERA_TIMEOUT이 발생하는지 확인한다.
4. 실패 회차에는 영상이 없는지 확인한다.

### 시나리오 E — 최근 영상 5장

1. 같은 플레이트를 6회 이상 성공 촬영한다.
2. 가장 오래된 성공 영상이 만료되는지 확인한다.
3. 촬영 이력의 회차 수가 줄지 않는지 확인한다.

### 시나리오 F — 반출 추적성

1. 촬영 이력이 있는 플레이트를 반출한다.
2. 슬롯이 빈 상태인지 확인한다.
3. 이력 검색에서 반출 플레이트를 찾는다.
4. 영상은 만료되고 Run 메타데이터는 유지되는지 확인한다.

## 22. 실장비 사용 전 주의

현재 프로그램은 가상장비 데모이며 실제 생산 장비에 바로 연결하면 안 된다. 실장비 적용 전에 최소한 다음 작업이 필요하다.

- 제조사/PLC 통신 규격 확정
- 실장비 어댑터 구현
- 하드웨어 리밋·도어·온도·비상정지 시험
- 명령 타임아웃과 재접속 정책
- 실제 카메라 파일 완료와 PC 전송 ACK 정의
- 사용자 권한, 관리자 위험 명령, 감사 로그
- 저장장치 장애와 전원 차단 복구 시험
- 현장 패널과 장갑 터치 검증

실장비 안전은 UI 상태에 의존하지 않고 PLC 또는 장비 컨트롤러에서 강제해야 한다.
