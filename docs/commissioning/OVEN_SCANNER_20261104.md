# OvenScanner 실 장비 점검 기록 (2026-11-04)

실 장비는 M1 camera Y/S1/J41, M2 camera X/S2/J40, M3 tray X/S3/J39,
M4 elevator Z/S4/J38 구성입니다. 기존 테스트베드의 축 배치와 구분합니다.

| 축 | 운용 범위 (STEP 펄스) | 검증 |
|---|---:|---|
| M1 camera Y | -12300 ~ 0 | 센서 간격 12568; 개별 원점/복귀/범위 거부 확인 |
| M2 camera X | 0 ~ 5300 | 센서 간격 5537; 개별 원점/복귀/범위 거부 확인 |
| M3 tray X | 기존 -40 ~ 2400 | 수동 제어 허용(USED=1), 범위/원점 미검증 |
| M4 elevator Z | 0 ~ 16900 | 센서 간격 17216; 개별 원점/복귀/범위 거부 확인 |

전체 센서 간격 측정은 200Hz, 이후 원점/중간 복귀 검증은 1000Hz로 수행했습니다.
M1/M2/M4 HFAST=HSLOW=1000, HPARK=0입니다. 단위는 STEP 펄스이며 USTEP=8입니다.
[장비별 저장 파라미터와 검증 범위](oven-scanner-20261104.json)는 보드 읽기 결과를 기록한 자료입니다.
시험 이후 작업자가 변경한 일반 속도/가속도 값은 앞선 검증의 대상이 아닙니다.

M4는 출력 OFF 중 중량으로 위치가 달라진 것으로 사용자 보고되어 센서 원점을 다시 찾아 복구했습니다.
출력 OFF/리셋 이후 이전 펄스 좌표를 실제 위치로 간주하지 않습니다.
운용 RANGE는 현재 HOMED=1일 때만 적용되며, 과거 검증 기록은 현재 원점 상태를 대신하지 않습니다.
양끝 플래그가 같은 센서를 작동시키므로 시작 시 감지 중인 끝단의 구분이 필요합니다.
M3는 이번 범위 시험에서 제외됐고 이후 수동 제어만 다시 허용했습니다.

펌웨어 수정, Windows 모터/센서 점검 화면, 원점·범위 시험 소스는
[MCB 펌웨어 저장소의 commissioning](https://github.com/eternity-00/colony_scanner_MCD_firmware_for_STM32F427ZIT6/tree/fix/real-machine-sensor-mapping-20261104/commissioning)에 있습니다.

이 기록은 자동 공정 레시피나 배포 프로필이 아닙니다. 이 저장소의 `profiles/` 또는
`COLONY_PROFILE`을 변경하지 않았으며, M3 및 전체 공정 검증 없이 이 축 구성을 스캔 시퀀스에 적용하지 않습니다.
