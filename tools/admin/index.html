프로필 — MCB — 카메라 — 점검 모드 꺼짐
점검 모드가 아닙니다. 읽기는 되지만 파라미터 변경 · 레시피 저장 · 모터 조작은 「점검 모드 시작」 뒤에만 됩니다. 점검 모드 동안 운영 화면의 촬영과 장비 조작은 막힙니다.

MCB 펌웨어 파라미터 (GET ALL)

칸을 고쳐 「변경 적용(SET)」을 누르면 RAM 에 바로 적용되고, 「플래시 저장(SAVE)」을 눌러야 전원을 꺼도 남습니다. 프로필 기대값과 다른 칸은 주황, 고친 칸은 초록입니다. 변경 전에 백업이 자동으로 남습니다.

검사: HMAX ≥ |RANGE|, SPEED·MAXSPEED 는 공진 구간(RESLO~RESHI) 밖, USTEP 변경 시 step 단위 값 전부 재확인(정렬 보정값도 무효가 됩니다).

공정 레시피

단 수, 웰 배치, 트레이 꺼냄 위치, 촬영 높이(풀스텝 — 앱이 USTEP 을 곱함), 웰 안지름, 정렬 중 카메라 축 속도. 저장 전 검증하며 이전 파일은 config/history 에 남습니다. 저장은 즉시 적용됩니다.
